О нас

Мы — студенты, изучающие Docker и веб-разработку.

Что делает этот сайт

Данный сайт представляет собой статический веб-ресурс, упакованный в Docker-образ на основе официального образа nginx. Собственный код (HTML и CSS) добавляется в образ с помощью инструкции COPY в Dockerfile.

Используемые технологии

  • Docker — контейнеризация приложения
  • nginx — веб-сервер для раздачи статики
  • HTML5 — разметка страниц
  • CSS3 — оформление
